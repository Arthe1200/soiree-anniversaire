# La Soirée — site d'anniversaire

Prototype français : informations publiques, budget transparent, espace organisateurs de démonstration, liste d'invités et contrôle d'entrée.

## Important — prototype uniquement

Cette version est une maquette front-end. Les données restent dans la session du navigateur et ne sont pas partagées entre appareils. L'inscription, les codes et le contrôle d'entrée ne sont pas sécurisés pour un événement réel. Ne saisissez pas de vrais mots de passe ou données personnelles.

Avant un usage réel, ajouter une authentification avec rôles côté serveur, base de données avec règles d'accès, QR codes vérifiés par serveur et protection contre la double entrée, ainsi qu'un prestataire de paiement adapté pour une éventuelle cagnotte.

## Prévisualiser

Ouvrir index.html dans un navigateur ou activer GitHub Pages. Si le dépôt reste privé sur GitHub Free, il faudra le rendre public pour utiliser GitHub Pages, ce qui rendrait aussi le code public. Ne publiez pas de secrets ni de données d'invités.
